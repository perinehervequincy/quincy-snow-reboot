# 🤖 Quincy Snow Reboot

**Glisse, collecte, développe et partage !**

Quincy Snow Reboot est un jeu vidéo 3D open source développé dans le cadre du projet Quincy Reboot et de sa communauté Quincy Family.

Inspiré de l'esthétique des jeux vidéo des années 1990, il propose une aventure rétro sur un toboggan enneigé suspendu dans le vide.

## 🎮 Jouer gratuitement

https://quincyreboot.fr/quincy-snow-reboot-v2.html

## ❄️ Fonctionnalités

- Univers 3D rétro low-poly.
- Petit robot comme personnage principal.
- Toboggan enneigé suspendu dans le vide.
- Collecte de tablettes informatiques.
- Obstacles, sauts et turbo.
- Score, chronomètre et trois vies.
- Musique originale et bruitages.
- Compatibilité PC et smartphone.
- Commandes clavier et tactiles.

## 🕹️ Commandes PC

| Touche | Action |
|---|---|
| ↑ | Accélérer |
| ↓ | Freiner |
| ← | Tourner à gauche |
| → | Tourner à droite |
| A | Sauter |
| Z | Turbo |

Sur smartphone, les commandes tactiles sont directement intégrées au jeu. Le mode paysage est recommandé.

## 💻 Installation

1. Télécharger le fichier quincy-snow-reboot-v2.html.
2. Ouvrir le fichier dans un navigateur moderne.
3. Cliquer sur Jouer.

Une connexion Internet est nécessaire pour charger la bibliothèque Three.js.

## 🏆 Quincy Snow Reboot – Open Source Challenge

Un concours communautaire de développement est en préparation !

L'objectif sera de créer la meilleure évolution de Quincy Snow Reboot.

### Récompense envisagée

Une tablette informatique pour le meilleur projet.

### Critères d'évaluation proposés

- Créativité et originalité : 30 points.
- Qualité du développement : 25 points.
- Jouabilité : 20 points.
- Design et graphismes : 15 points.
- Documentation du code : 10 points.

Les dates, les conditions de participation et le règlement officiel seront communiqués ultérieurement.

## 🤝 Comment contribuer ?

1. Créer un fork du dépôt.
2. Modifier ou améliorer le jeu.
3. Tester les modifications.
4. Documenter les améliorations.
5. Proposer une Pull Request.

Les contributions seront examinées avant leur intégration dans la version officielle.
